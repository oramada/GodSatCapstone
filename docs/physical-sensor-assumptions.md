# Sensor assumptions for the supplied design

The user authorized documented simulation assumptions on 2026-10-25 after inspection of the governing manuscript. The manuscript supplies seven factor ranges and a design workflow but no calibrated sensor hardware, published actor–critic baseline configuration or operational false-track definition. The new configuration is [governing-design-physical-leo.json](../configs/archive/governing-design-physical-leo.json). It produces a separate campaign; the earlier proxy-based campaigns are preserved.

The sensor is a hypothetical single-axis equivalent pointing gimbal with inertia 2 kg m², maximum torque 0.02 N m, maximum angular speed 2 degrees/s, motor efficiency 0.65 and 0.05 W of drive electronics power while moving. These values are assumptions rather than estimates for CASSIOPE or any other spacecraft. Motion starts and ends at rest at each observation. Acceleration is torque divided by inertia. Short slews have a triangular velocity profile; longer slews reach the speed bound and have a trapezoidal profile. Acceleration and deceleration occupy finite time; an observation is masked if its slew cannot finish within the 60-second step. This construction follows the standard acceleration/cruise/deceleration trajectory structure described in [MathWorks' trajectory documentation](https://www.mathworks.com/help/robotics/ug/design-a-trajectory-with-velocity-limits-using-a-trapezoidal-velocity-profile.html).

The modeled electrical slew energy is `0.5 × inertia × peak_speed² / efficiency + drive_power × slew_duration`, in joules. Braking dissipates kinetic energy and does not regenerate electricity. Holding power, friction, reaction-wheel momentum management, settling vibration, tracking motion and sensor exposure energy are excluded. This is a dimensioned idealized actuator model, not a measured spacecraft power budget. Each response reports mean joules per host per step and total episode joules. Reward normalization uses the configured maximum-speed kinetic term plus 60 seconds of drive power.

Each accepted target look produces either a nominal true detection or a missed detection using the original range/element-age-dependent detection model. Conditional on a missed detection and no sensor dropout, a separate independent uniform draw produces a clutter return incorrectly associated with that target with probability 0.005. A true return takes precedence. An injected complete sensor outage suppresses both true and false reports. This is a Bernoulli association-error assumption, without an image renderer, measured point-spread function, or calibrated clutter density.

Any reported detection creates or refreshes a declared track for the configured 180-second custody interval. The most recent association labels that track as true or false in simulation truth. **False-track rate** is false active declared-track slots divided by all active declared-track slots, restricted to currently valid target states. **False-observation rate** is false reports divided by all reports. A zero denominator is reported as zero together with its count. The model does not require multi-hit confirmation and has a finite catalogue-indexed track space; it cannot measure false unassociated objects or operational false discovery rates.

The policy observes reported track age, including false reports. True custody uses a separate last-true-detection state; clutter never earns true custody. Ground truth is available to the simulated training reward and evaluation, and is never silently used to correct the observed track age. The reward is true custody minus normalized physical slew, active false-track and coordination-conflict penalties. The actor/critic topology, 40 training episodes, historical windows, six hosts, 18 targets and baseline factor settings are the documented simulation reference. They are not a recovered published baseline.

Orbital geometry is sampled every 60 seconds and held at the slot boundary for the tasking decision. The model checks that the rest-to-rest slew fits within the slot; it does not propagate an exposure timestamp through the continuous slew or resolve settling and target motion within that slot. The 40-episode training budget supports comparison under a fixed finite budget, without establishing policy convergence or operational optimality.

Nominal detections, dropout and clutter use independent seeded random streams. The fixed factor design, training seeds and held-out five-seed protocol are retained. Factor ranking is measured from the new experiment; the manuscript's claimed learning-rate/discount/width ranking is not imposed. The paper's 11–14% custody and 9% energy improvements are hypotheses to check, not values to reproduce by construction.

An assumed 50 W host power multiplied by measured treatment wall duration provides an explicitly labeled host-energy scenario estimate. It is separate from calibrated machine energy, GPU usage and gimbal energy. CPU campaigns report zero GPU-hours; this is not evidence of GPU efficiency. Neither the host power assumption nor actuator parameters were fitted to the observed effects.

The analysis will retain results under alternative clutter probabilities, inertia/torque assumptions and drive power rather than claiming that this nominal assumed hardware is uniquely correct. The historical/dropout campaigns in the main report retain their original sensor model unless their configuration explicitly selects this model.
